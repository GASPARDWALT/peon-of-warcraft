Garder ta progression

Pour sauvegarder dans le jeu : Start → SAVE. Le lecteur conserve aussi ta session sur cet appareil.

Quelle sauvegarde choisir ?

Le fichier .sav contient la sauvegarde faite avec SAVE. La session conserve exactement l’écran, la partie en cours et l’horloge émulée. Dans ce lecteur, l’horloge avance pendant le jeu et reste en pause quand la page est fermée.

Les fichiers restent dans ton navigateur. Exporte-les pour changer d’appareil ou avant d’effacer ses données.
