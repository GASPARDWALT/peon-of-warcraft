# Peon of Warcraft v0.2.9 browser player

This branch contains the exact-ROM, self-contained browser player tested in
managed Chromium. The previous v0.2.7 player is retained in archive/v0.2.7/.

ROM SHA-256: 4530c718bf299ec9e1c8de8c52895906a81024345bd60717cd5c99dbd30b8a93.

Publishing this branch does not enable GitHub Pages. The owner must select
Settings > Pages > Deploy from a branch > gh-pages > /(root) > Save.

Until hosting is confirmed, download the browser ZIP and read the instructions:
https://github.com/GASPARDWALT/peon-of-warcraft/blob/main/docs/BROWSER_PLAYER_V029.md

Chrome/Edge, keyboard, touch, audio, battery save and session checkpoints are
tested over HTTP. file://, Safari/iPhone, physical gamepads and Chromatic/DevDay
hardware remain unverified. No cartridge has been programmed.
