# Peon of Warcraft — Spell Effects Pack v1

Transparent PNG spell and combat-ability effects in a Warcraft-inspired,
Game Boy Color / Pokémon Crystal-era pixel-art style.

## Contents

For every spell or ability:
- icon: 16×16
- player/back-cast effect
- enemy/front-cast effect
- optional impact/explosion
- one combined transparent sheet

## Orientation convention

- `player_back`: used when the player's back-facing combat sprite casts toward the enemy.
- `enemy_front`: used when a front-facing enemy casts toward the player.

## Native sizes

- spell icon: 16×16
- small projectile / small impact: 16×16
- large explosion / aura: 32×32
- elongated lightning: 16×32
