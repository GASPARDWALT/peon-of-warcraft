# Missing player variants from supplied artwork

Class order: base, Shaman, Warrior, Warlock. World 16×16, front combat 56×56, rear combat 48×48. Original user files untouched. `manifest.json` records source hashes and distinguishes derived body pixels from newly authored missing heads, backs and equipment. Editable whole-pixel rows accompany every PNG. Binary transparency. Sources contain at most 16 visible colours; native GBC conversion is a separate integration stage. This gallery is source art, not a ROM capture.
