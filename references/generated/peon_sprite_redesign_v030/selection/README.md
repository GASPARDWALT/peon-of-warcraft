# Class-master selection proposal

Three screens authored at exactly 160 × 144 pixels, using the supplied ornate brown Warcraft interface as inspiration. The original master references guide their identities. These images are proposals, not ROM screenshots.

- `class_master_kento_160x144.png`: Kento Brandenhoof, Tauren Shaman, blue accent.
- `class_master_zogzog_160x144.png`: MoCMoc Zogzog, Orc Warrior, red accent.
- `class_master_xasthur_160x144.png`: Xasthur, Undead Warlock, purple accent.
- `master_*_portrait_64x68.png`: reusable transparent portraits.
- `*_preview_6x.png`: enlarged with nearest neighbour; not native game assets.
- `class_master_selection_contact_sheet.png`: three native states side by side.
- `index.html`: click the names or use arrow keys to inspect the proposal.

Every stroke was authored in whole native pixels; there is no antialiasing or automatic photo reduction. Text uses fixed native pixel glyphs. Colours are quantized to RGB555. Conversion into eight background palettes of four colours per tile, tileset layout and ROM integration still need implementation and review. The portraits deliberately depict experienced masters, rather than the apprentice player.

The refined frame uses carved wooden bands, gilded corners, riveted iron straps and a slim carved divider. The class symbols are a blue lightning bolt, red axe and purple skull; their reusable transparent sources are `class_icon_*_12x14.png`. Details were added to the masters’ eyes, skin, armour and robes while keeping the text regions clear.
