# Native region quest points

Transparent 8×8 `!` and `?` glyphs use the existing gold OBJ palette. The Den shows the Lazy Peons Foreman; Valley of Trials shows Galgar. A completed quest removes its point. Undiscovered regions reveal no point.

These static previews are compiler reconstructions; emulator captures and checks are reported separately by `validate_peon_atlas_quests.py`.
