# Peon of Warcraft v0.2.15

Ouvrir peon_of_warcraft_v0_2_15.gbc dans un émulateur Game Boy Color ou sur ModRetro.

`runtime/` contient des captures natives160×144 de cette ROM testée et leurs agrandissements4×nearest. `assets/static_imports/` contient des PNG24×24 transparents réutilisables, issus de l'import natif ; cette galerie d'assets est distincte des captures du jeu. Les sprites sont agrandis sans lissage. Les Kolkar historiques sont seulement agrandis ; aucun nouveau dessin de Kolkar n'est revendiqué.

`validation/` contient les preuves déclarées PASS. Le matériel physique ModRetro n'a pas été testé.

ZIP déterministe : noms triés, date fixe et compression fixe. Chaque membre est relu avec son CRC et son SHA256 après écriture. `SHA256SUMS.txt` vérifie les fichiers du ZIP ; le SHA256 du ZIP lui-même est fourni dans le manifest externe et le fichier .zip.sha256, car un fichier ne peut pas contenir son propre hash sans circularité.
